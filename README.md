# presscode

Press CSV/TSV code tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/presscode/

## Install / run

```bash
git clone https://github.com/theworker02/presscode.git
cd presscode
node src/cli.js
node --test
```
